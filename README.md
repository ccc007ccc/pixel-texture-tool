# Pixel Texture Tool

一个面向像素贴图工作流的本地 Web 工具，用于把图片降采样到指定分辨率，并逐格控制每个输出像素的采样方式。

## 功能

- 拖拽、点击或粘贴图片导入
- 主采样视图保留整图上下文
- 选中采样区域局部预览
- 结果预览、复制结果图、保存 PNG
- 三种逐格采样算法
  - `anchor-point`
  - `multi-point-average`
  - `cell-average`
- 单格自定义采样点
- 单格手动颜色覆盖
- 撤回与双击重置当前格
- 主视图平移、滚轮缩放、采样区域移动与缩放

## 本地运行

```bash
npm install
npm run dev
```

默认启动后访问终端输出的本地地址。

## 构建

```bash
npm run typecheck
npm run build
```

## 使用说明

1. 导入一张图片。
2. 设置输出宽高，按需保持原图比例。
3. 在主采样视图中单击选中输出像素。
4. 通过左侧面板切换当前格的采样算法。
5. 在主视图调整采样区域，在局部视图拖动采样点或设置手动颜色。
6. 使用复制或保存导出结果。

## 交互说明

- 主采样视图：
  - 左键选中当前格
  - 单点采样模式下可直接拖动 anchor
  - 右键拖动采样区域，拖边或角点调整大小
  - `Space + 左键` 或中键平移
  - 滚轮以鼠标位置为中心缩放
- 局部视图：
  - 单点模式可拖动采样点
  - 多点模式可点击或右键添加点
  - 点击颜色块可预览并提交手动颜色
- 快捷键：
  - `Ctrl/Cmd + Z` 撤回
  - 主视图双击重置当前格采样配置

## 浏览器兼容性

- 需要支持 Canvas 2D 和 Pointer Events 的现代浏览器
- 复制图片依赖 `ClipboardItem` 与 `navigator.clipboard.write`
- 如果浏览器不支持图片写入剪贴板，请改用保存 PNG

## 已知限制

- 超大图片或很高的输出分辨率会带来明显的 Canvas 重绘开销
- 当前主要面向桌面浏览器交互，未针对移动端做专门优化
- 仓库默认不包含示例图片与构建产物
